# DMS Enhancer

A lightweight browser extension designed to streamline document processing and previewing on the DILG Document Management System (DMS).

Developed by **[lstvelasco](https://luisitovelasco.netlify.app/)**

---

## 🚀 Features

- **Automated Bulk Actions:**
  - **Incoming Documents:** Select multiple items and perform **Bulk Accept** in one click.
  - **Pending Documents:** Select multiple items and perform **Bulk Complete** in one click.
- **Instant PDF Previews:**
  - **Pending Documents Table:** Click **Quick Preview** next to any item to view its attached PDF instantly via a modal popup.
  - **Document Details View:** View PDF attachments directly in a clean popup overlay without leaving the page or opening new tabs.
- **Safe Batch Processing:** Allows up to 15 items per batch for consistent and reliable document routing.
- **In-Page Dashboard Bar:** Embedded status bar showing current tool version, selection counts, and quick access links.

---

## 🛠️ How to Install in Your Browser

1. **Download the Extension:**
   - Download the latest `dms-enhancer.zip` release file.
2. **Extract the Zip File:**
   - Extract the `.zip` file to a folder on your computer (e.g., inside `Documents`).
3. **Open Browser Extension Settings:**
   - **Google Chrome:** Go to `chrome://extensions/`
   - **Microsoft Edge:** Go to `edge://extensions/`
4. **Enable Developer Mode:**
   - Toggle on **Developer mode** (top-right switch in Chrome, or left sidebar toggle in Edge).
5. **Load the Extension:**
   - Click **Load unpacked** and select the extracted extension folder.
6. **Start Using:**
   - Navigate to `dms.dilg.gov.ph` to start using Bulk Actions and Quick Previews.
